# Profile assets

Real Animal Battle Stats screenshots captured from its live website on October 8, 2026:

- `screenshots/animal-battle-stats-home-2026-10-08.jpg` — https://animalbattlestats.com/
- `screenshots/animal-battle-stats-database-2026-10-08.jpg` — https://animalbattlestats.com/stats
- `screenshots/animal-battle-stats-orca-2026-10-08.jpg` — https://animalbattlestats.com/stats/orca

`activity-graph.svg` is generated by `scripts/update_activity_graph.py` from GitHub’s contribution-calendar API. The scheduled/manual workflow is `.github/workflows/profile-activity.yml`. It commits only a changed graph; a failed fetch leaves the last good image intact.

Older logo and preview files are retained for history and compatibility.
